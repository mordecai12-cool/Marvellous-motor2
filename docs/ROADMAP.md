# Next marketplace milestones

The current local upgrade is a tested showroom and manual enquiry milestone. The attached master brief is a longer product roadmap; the following capabilities remain outstanding.

1. **Foundation and authentication:** formal schema migrations, foreign keys and constraints, recoverable transactional workflows, verified email/password recovery, administrative roles, revocation, structured audit logs, and production secret configuration.
2. **Verified dealer publishing:** dealer businesses, private verification submissions, admin approval, seller profiles, multiple-image uploads, inventory editing, moderation, leads, staff access, and commission/subscription configuration. Current dealer applications are stored manual enquiries only.
3. **Reservations and commerce:** real availability, atomic reservations, order transitions, invoices, integer monetary storage, payments through documented Paystack/Flutterwave sandbox integrations, signed webhooks, idempotent reconciliation, refunds, and authorised financial actions. The inherited manual receipt flow remains for local review.
4. **International sourcing:** sourced offers, itemised quotations, customer approval, verified inspection documents, agreements, supplier adapters, purchase milestones, and manual shipping events with references and authorised updater identities. Current requests and estimate calculator are functional; actual procurement and tracking are not connected.
5. **Shipping and delivery:** authenticated and auditable manual milestones first; carrier updates only through documented authorised integrations. No live shipment events are currently displayed.
6. **Customer/dealer operations:** messages, notifications, support conversations, transaction-linked reviews, price alerts, saved-search notifications, trade-in valuations, finance partner workflows, and analytics. Current saved searches are browser-local and enquiry status updates are manual.
7. **International presentation and discovery:** user-configured locale, legally usable currencies and verified rates, model/media galleries, supplier inventory feeds, structured metadata for genuine live listings, and canonical/sitemap configuration using the real production domain.
8. **Production delivery:** privacy review, original tracked data removal from deploy artifacts, PostgreSQL/object storage where warranted, backups and restore drills, CI, container packaging, monitoring, production accessibility/performance tests, and a reviewed hosting configuration.

External providers should be connected through documented, authorised adapters using sandbox credentials first. The local milestone makes no claims about supplier partnerships, financing availability, verified inspections, warranties, or production payment processing.

The immediate design follows the user's explicit royal-blue/sky-blue request. A dark/champagne theme from the longer brief can be implemented as an optional theme in a later design milestone.
